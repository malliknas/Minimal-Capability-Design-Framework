Appendix C: Cross-Validation Performance Matrices

Documents comprehensive performance matrices, statistical reliability metrics, and deployment viability assessments for all 10 validation tests (T1-T10). Employs repeated trials methodology (5 independent measurements per variant) with 95% confidence intervals calculated using Wilson score method for binomial proportions. Includes trial-by-trial execution traces, resource efficiency classifications, and categorical performance analysis across three quantization tiers (Q1: simulated 1-bit constraints, Q4: 4-bit quantization, Q8: 8-bit quantization).

This appendix provides empirical evidence supporting MCD's constraint-resilience principles through rigorous comparative analysis of prompt engineering strategies (MCD vs Chain-of-Thought vs Few-Shot), context management approaches (stateless regeneration vs implicit reference), and resource optimization patterns (token efficiency, latency, memory stability). All validation frameworks were executed in WebAssembly (WebLLM) offline browser environments, ensuring reproducibility and ecological validity for real-world edge deployment scenarios.

Statistical Methodology: With n=5 trials per variant approach, the analysis focuses on categorical differences and effect size magnitude rather than traditional inferential statistics. Where extreme binary outcomes exist (e.g., 100% vs 0% completion), Fisher's Exact Test validates categorical distinctions. For continuous metrics (token efficiency, latency), descriptive statistics (means, standard deviations, 95% CIs) are provided alongside cross-tier replication (Q1/Q4/Q8 validation) as primary evidence of reliability. Statistical power is limited by small per-variant sample sizes, though extreme effect sizes and consistent cross-tier patterns strengthen validity claims beyond isolated performance snapshots.

Statistical Notes for T3

Equivalent Recovery Success: Both structured and conversational fallback approaches achieved 100% recovery success rate across all three quantization tiers (Q1, Q4, Q8) with zero failures (15/15 trials total per approach). This validates that fallback prompt design—rather than specific architectural approach—determines recovery effectiveness in stateless systems. The categorical equivalence is validated through consistent binary outcomes across independent model tiers.

Token Efficiency Trade-off: Structured fallback consistently achieved 7-35% token reduction across tiers: Q1-tier (66 vs 71 tokens, 7% reduction), Q4-tier (202 vs 208 tokens, 3% reduction), Q8-tier (136 vs 208 tokens, 35% reduction). This confirms that explicit field-based clarification provides resource efficiency advantages while maintaining equivalent functional outcomes. The effect size for Q8-tier token reduction represents a large practical difference (Cohen's d > 0.8).

Latency Counterintuitive Finding: Conversational fallback showed faster processing (1,072ms vs 1,300ms on Q1-tier, representing 18% latency reduction), despite conventional assumptions suggesting structured prompts process faster. This may be attributed to simpler linguistic patterns in conversational responses requiring less generative complexity.
